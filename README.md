# Rhythm

AI scheduling and productivity assistant — monorepo for iOS client and backend API.

## Structure

```
Rhythm/
├── rhythm-ios/      # SwiftUI iOS app (Xcode)
└── rhythm-backend/  # Backend API (coming soon)
```

## rhythm-ios

Voice-first task management app. See [rhythm-ios/README.md](rhythm-ios/README.md) for setup, architecture, and development.

```bash
cd rhythm-ios
open Rhythm.xcodeproj
```

## rhythm-backend

Backend API for planning, parsing, and sync. Under active development.
